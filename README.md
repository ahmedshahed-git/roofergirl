# 🚨 EXTREMELY IMPORTANT — ANIMATION IS THE #1 PRIORITY

The most important requirement of this entire project is the animation and motion design.

DO NOT create a normal website with a few fade-in animations.

The website must feel **cinematic, fluid, immersive, sophisticated, and visually addictive**.

When someone opens the website, they should immediately think:

**“This looks expensive.”**

The motion should feel intentionally art-directed, like a premium architecture / construction / luxury creative agency website.

Avoid generic AI website animations.

DO NOT use:

* Random bouncing animations
* Excessive spinning
* Cheap glowing effects
* Cartoonish motion
* Repetitive basic fade-ins everywhere
* Every element moving at the same time
* Excessive animation that makes the site feel messy

Instead use:

* Cinematic reveals
* Smooth parallax
* Layered depth
* Scroll-driven motion
* Mask reveals
* Clip-path transitions
* Scale transitions
* Slow cinematic zoom
* Image/video movement
* Staggered typography
* Elegant hover interactions
* Section-to-section transitions
* Subtle floating elements
* Smooth easing
* Carefully controlled timing

Animation should feel **luxurious and deliberate**, not excessive for the sake of being flashy.
